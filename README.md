# Прогнозирование рисков ДТП в мегаполисе

Инструмент для пространственно-временного прогнозирования рисков возникновения
дорожно-транспортных происшествий в мегаполисе методами машинного обучения и
геоинформационного анализа. Репозиторий содержит исходный код вычислительного
конвейера, генератор синтетического набора данных, процедуру обучения и оценки
моделей, а также готовые результаты экспериментов и рисунки.

## Результаты

На тестовом периоде (2025 год) лучшие показатели показали реализации
градиентного бустинга:

| Модель | Точность | Полнота | F1 | ROC-AUC | PR-AUC |
|---|---|---|---|---|---|
| Логистическая регрессия | 0,692 | 0,637 | 0,663 | 0,954 | 0,734 |
| Случайный лес | 0,674 | 0,683 | 0,678 | 0,954 | 0,743 |
| LightGBM | 0,692 | 0,693 | 0,693 | 0,959 | 0,763 |
| XGBoost | 0,712 | 0,674 | 0,693 | 0,958 | 0,765 |
| Статистическая модель | 0,685 | 0,571 | 0,623 | 0,915 | 0,663 |

Полные метрики, матрицы ошибок и подобранные гиперпараметры сохранены в
`results.json`, важность признаков — в `feature_importance.json`, история
подбора — в `optuna_history.json`.

## Структура репозитория

```
.
├── src/
│   ├── nir_pipeline.py       # генерация данных, признаки, обучение, оценка, графики
│   └── make_report_figs.py   # перегенерация отдельных рисунков для отчёта
├── fig/                      # готовые рисунки (PDF и PNG)
├── results.json              # метрики моделей и матрицы ошибок
├── feature_importance.json   # важность признаков модели LightGBM
├── optuna_history.json       # значения целевой функции по испытаниям Optuna
├── requirements.txt
└── README.md
```

## Установка

Требуется Python 3.12 или новее. Рекомендуется виртуальное окружение:

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

Полный конвейер (генерация данных, обучение, оценка и построение рисунков):

```bash
python src/nir_pipeline.py
```

Скрипт создаёт каталог `fig/` и обновляет файлы `results.json`,
`feature_importance.json` и `optuna_history.json`. Время выполнения зависит от
числа испытаний Optuna; настройка выполняется на подвыборке 200 000 наблюдений.

Перегенерация отдельных рисунков отчёта:

```bash
python src/make_report_figs.py
```

Каталог для сохранения можно переопределить переменной окружения `FIG_DIR`:

```bash
set FIG_DIR=C:\path\to\fig
python src/make_report_figs.py
```

## Данные

Используется синтетический набор данных, воспроизводящий статистическую
структуру городской аварийности: регулярная сетка 30 × 30 ячеек, период
2023–2025 годов, 986 400 наблюдений «ячейка — сутки», 27 признаков и доля
положительного класса 7,27 %. Синтетическая выборка позволяет строго проверить
корректность конвейера и сравнить алгоритмы в контролируемых условиях.
Генератор детерминирован: фиксированное зерно `RANDOM_STATE = 42` обеспечивает
воспроизводимость результатов.

## Методика

- Пространственные признаки: плотность улично-дорожной сети, число перекрёстков,
  число полос, ограничение скорости, удалённость от центра, плотность объектов
  притяжения, центральность.
- Временные признаки: месяц, день недели, выходные, праздники, сезон отпусков,
  циклические составляющие дня года.
- Контекстуальные признаки: температура, осадки, видимость, ветер, снегопад,
  туман, плотность транспортного потока.
- Пространственно-временные лаги: происшествия за предыдущие сутки, скользящее
  среднее за неделю, среднее по соседним ячейкам.

Данные разделяются по времени: обучение — 2023 год и три квартала 2024 года,
валидация — IV квартал 2024 года, тест — 2025 год. Порог классификации
подбирается по валидации и фиксируется для теста.
